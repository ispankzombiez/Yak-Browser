YakBrowser

Open-source, Community-built

About

YakBrowser is an open-source Android browser for the monster-collecting game Yakkamon. The game normally refuses to run unless your phone is held sideways — YakBrowser lets you play in portrait mode, holding your phone the normal way, with a fullscreen immersive experience and a built-in settings gear right on the game screen.

Features

  • Play Yakkamon in portrait mode (no more holding your phone sideways)
  • Orientation lock toggle — prefer landscape? One switch in settings
  • Fullscreen immersive gameplay with the screen kept on
  • Yakkamon links open in-app; everything else opens in your default browser
  • Quick access to settings via a corner gear — no leaving the game
  • Completely open-source and community maintained

A Note For Players

  • The app defaults to portrait lock ON: the screen stays portrait and the game is told it's in landscape, so it plays normally while you hold your phone upright.
  • To change settings, tap the small gear icon in the top-left corner of the game screen.
  • Inside settings, the "Lock orientation" switch controls this behavior: ON = play in portrait; OFF = the app follows your phone's sensor with no spoofing at all.
  • Optional: the "Settings access" switch hides the floating gear for a cleaner game screen. Settings stay reachable either way — long-press the YakBrowser icon and tap Settings (works on every phone), or open your device's App info page for YakBrowser and tap “Configure in YakBrowser” (shown on some phones, e.g. Samsung).
  • Links that leave yakkamon.com open in your default browser instead of inside the app.

How to Install

  1. Download the latest APK directly from GitHub: Latest Release

    The APK is named yakbrowser-v[version].apk
  2. Enable "Install from Unknown Sources" on your Android device when prompted (usually in Settings > Security).
  3. Open the downloaded APK and install it.

For advanced users

You can build the app from source using Android Studio or the provided Gradle scripts.

  1. Clone or download the repository to your computer.
  2. Open a terminal in the project root directory.
  3. Connect your Android device via USB and ensure USB debugging is enabled (see how to enable USB debugging).
  4. Run .\gradlew.bat installDebug (Windows) or ./gradlew installDebug (Linux/macOS) to build and install the debug APK directly to your connected device.
  5. If you prefer, you can still find the APK in app/build/outputs/apk/debug/app-debug.apk and install it manually.

For more details or troubleshooting, see the README or open an issue on GitHub.

Safety

  • Be cautious of websites or apps impersonating this project or Yakkamon. Always verify URLs and sources before entering sensitive information.
  • Only install the app from trusted sources, such as this project's official GitHub releases. Avoid downloading APKs or content from unknown or suspicious sites.
  • YakBrowser itself stores no accounts, keys, or personal data — it simply displays yakkamon.com.
