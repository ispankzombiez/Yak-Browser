YakBrowser

Open-source, Community-built

About

YakBrowser is an open-source Android browser for the monster-collecting game Yakkamon. The game was designed for landscape — YakBrowser offers optional portrait mode, improved portrait layouts, and configurable game settings. By default, the app follows your phone's rotation; enable Lock orientation to play upright.

Features in the Current Source

  • Optional portrait mode, with a confirmation about possible layout issues when enabling orientation lock
  • Improved portrait menus, caught-Yakkamon popups, PvP “See all” lists, and battle framing that fits your team on screen
  • Optional Top vs bottom battles in portrait: your team below, enemies above
  • Main and Notifications settings tabs
  • Optional Clock top-left and Enlarge bottom bar portrait HUD controls
  • Independent Keep status bar visible and Keep navigation bar visible toggles; fullscreen with swipe-to-reveal by default
  • Optional Keep screen on during gameplay
  • Arrival alerts and regular battle-challenge refresh reminders, with permission controls, optional exact timing, and a test notification
  • Yakkamon links open in-app; everything else opens in your default browser
  • Quick settings access via the corner gear, or the app icon's long-press Settings shortcut on Android 7.1+ with a supported launcher
  • Completely open-source and community maintained

Android Compatibility

Minimum Android version: Android 7.0 (API 24).

Keep Android System WebView updated to the latest version available for your device. The game and some features depend on WebView capabilities, so older versions may behave differently. This latest build has not yet been verified on Android 7 hardware.

A Note For Players

  • All Main switches default OFF on a fresh installation; previously saved choices are preserved. Notification controls are separate.
  • To change settings, tap the small gear icon in the top-left corner of the game screen.
  • In the Main tab, “Lock orientation” controls rotation: ON = portrait play after a confirmation; OFF = the app follows your phone's sensor with no orientation spoofing.
  • Optional: the "Settings access" switch hides the floating gear for a cleaner game screen. Before hiding it, confirm you can long-press the YakBrowser icon and tap Settings (Android 7.1+ with a supported launcher), or open your device's App info page for YakBrowser and tap “Configure in YakBrowser” (shown on some phones, e.g. Samsung).
  • “Keep screen on”, both Android bar visibility switches, and the portrait HUD options are opt-in. “Top vs bottom battles” applies during preparation, or the next battle if combat has started.
  • The Notifications tab includes arrival alerts, “New battle challenges”, permission status (Enable or Granted), optional exact alarm timing, and “Send test notification”.
  • Open the game to learn arrival timers and open Battles to learn its next challenge refresh. Battle reminders are one-shot: open Battles again to schedule the next refresh. Farm-visitor reminders are tentative; Android may delay alerts unless exact timing is enabled and permitted.
  • “Reload game” is available in settings and the icon’s long-press menu. About contains the version, privacy policy, and support contact.
  • Links that leave yakkamon.com open in your default browser instead of inside the app.

How to Install

  1. Download the latest APK directly from GitHub: Latest Release

    The APK is named yakbrowser-v[version].apk
  2. Enable "Install from Unknown Sources" on your Android device when prompted (usually in Settings > Security).
  3. Open the downloaded APK and install it.

For advanced users

You can build the app from source using Android Studio or the provided Gradle scripts.

  1. Clone or download the repository to your computer.
  2. Open a terminal in the project root directory.
  3. Connect your Android device via USB and ensure USB debugging is enabled (see how to enable USB debugging).
  4. Run .\gradlew.bat installDebug (Windows) or ./gradlew installDebug (Linux/macOS) to build and install the debug APK directly to your connected device.
  5. If you prefer, you can still find the APK in app/build/outputs/apk/debug/app-debug.apk and install it manually.

For more details or troubleshooting, see the README or open an issue on GitHub.

Safety

  • Be cautious of websites or apps impersonating this project or Yakkamon. Always verify URLs and sources before entering sensitive information.
  • Only install the app from trusted sources, such as this project's official GitHub releases. Avoid downloading APKs or content from unknown or suspicious sites.
  • YakBrowser itself stores no accounts, keys, or personal data — it simply displays yakkamon.com.
